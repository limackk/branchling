# Brand assets

The branchling mark is a lowercase **b** whose bowl separates from the stem at
its base and leans away from it, like a shoot growing out of a trunk: one task
branches into a smaller one. The same b opens the wordmark.

These files are the versioned source for every place the project shows its
identity — the README header, the viewer, the GitHub social preview and the
organisation avatar. They are not part of the npm package.

## Files

| File | Use |
|---|---|
| `logo/branchling-horizontal-color.svg` | Symbol and wordmark on a light background, transparent. |
| `logo/branchling-horizontal-on-dark.svg` | The same lockup for dark backgrounds; carries its own `#171514` background. |
| `logo/branchling-horizontal-mono-black.svg` | One-colour version for light backgrounds and print. |
| `logo/branchling-horizontal-mono-white.svg` | One-colour version for dark backgrounds, transparent. |
| `logo/branchling-symbol-color.svg` | The symbol alone, transparent: favicons and small spaces. |
| `logo/branchling-symbol-on-dark.svg` | The symbol on its own `#171514` background. |
| `social/og-1200x630.png` | GitHub social preview and link cards. |
| `social/avatar-1080.png` | Square avatar for the GitHub organisation and social profiles. |

## Palette: graphite and tangerine

| Token | Light | Dark |
|---|---|---|
| Primary | `#1E1C1A` | `#F5F2EE` |
| Secondary | `#3A3632` | `#D8D3CC` |
| Accent | `#D9480F` | `#FF7A3D` |
| Background | `#FBF9F6` | `#171514` |

The accent belongs to the bowl of the b. Use the dark-scheme variant whenever
the background is dark: the graphite stem of the light variant disappears there.

## Size and clear space

- Clear space on every side: the height of the wordmark's lowercase letters.
- Minimum height of the horizontal lockup: 24 px on screen, 8 mm in print.
- Minimum size of the symbol: 16 px, which is the favicon case.
- Do not stretch, recolour, rotate or outline the mark, and do not place it on a
  background where its contrast falls below 3:1.

## Typeface

The wordmark is set in Manrope 700, converted to outlines, so no font file is
needed to render it. Manrope is licensed under the SIL Open Font License 1.1,
which permits that conversion.

## AI disclosure

The mark was produced with AI involvement (Brand Studio, Claude and
VectorCraft); every design decision was made by the project owner. Each SVG
states this in its `<desc>` element, as synthetic content within the meaning of
Article 50 of the EU AI Act. Keep that element when editing or deriving a file.
